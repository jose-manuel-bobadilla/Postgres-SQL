# Video Game Store - PostgreSQL 

Proyecto personal para aprender caracteristicas de postgres SQL.

## Descripción
Base de datos de videojuegos con consultas de Arrays, JSON y Window Functions.


## Características
- Operaciones con ARRAY (filtrar, contar, agregar elementos)
- Almacenamiento y consultas JSON/JSONB
- Window Functions (ROW_NUMBER, RANK)
- Agregaciones  con GROUP BY y LATERAL

## Requisitos
- PostgreSQL 13+
- pgAdmin (opcional)

## Uso
1. Crear BD: `CREATE DATABASE videogame_store;`
2. Ejecutar `schema.sql`
3. Ejecutar consultas en `queries.sql`

## Conceptos aprendidos
- Funciones de ARRAY
- Operadores JSONB
- Window Functions
- LATERAL para expandir arrays
- GROUP BY con agregaciones
- Consultas de Arrays
